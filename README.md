# Digital Image Processing – BT24ECI043

Lab work and mini-projects for the Digital Image Processing course.

## Files

- `grey_conversion_script.py` – Converts an image to grayscale and extracts its Red, Green, and Blue channels
- `input.jpg` – Sample input image
- `output.png` – Output of the grayscale/RGB channel script
- `Tambola_ticket.py` – Generates valid Tambola (Housie) tickets
- `Tambola_output.png` – Sample output of the Tambola generator

## How to Run

```
pip install opencv-python matplotlib numpy
python grey_conversion_script.py
python Tambola_ticket.py
```

## Requirements
- Python 3.x
- OpenCV
- NumPy
- Matplotlib
